# Food Images Dataset

This folder is for **NutriServe game food images**.

## How to Use

1. **Name your images** exactly as the food ID (case-sensitive)
2. **Supported formats**: JPG, PNG, WebP
3. **Drop images here** and use the Admin panel to bulk upload

## After Uploading

1. Go to Admin tab in the app
2. Click "Bulk Upload Food Images"
3. System will process all images from this folder
4. Images will be available to all users immediately

## Image Guidelines

- **Minimum size**: 800x800px
- **Recommended**: Square aspect ratio
- **Quality**: High resolution (will be auto-resized)
- **Background**: Clean, well-lit
- **Content**: Show the prepared dish clearly
